


=== Console agent 4.2.0

This release of the Console agent includes security improvements, bug fixes, and the following features:

The 4.2.0 release is available for standard mode and restricted mode.

.Updates to the configuration check for Console agent installations
The Console agent now checks for both previous and current endpoints when performing a configuration check. If you have not updated to the new endpoint list for 4.0.0 or higher, installations succeed if the system can reach the previous endpoint list.
