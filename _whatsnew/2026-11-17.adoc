=== Console agent 4.13.0

The 4.13.0 release supports both standard mode and restricted mode.

This release of the Console agent includes security improvements and bug fixes as well as the following new feature. When you upgrade a vCenter-deployed Console agent to 4.13.0 by using an ISO, ensure that the VM is restarted after the upgrade finishes. The VM might restart automatically.

==== Create the AWS deployment role automatically when you deploy a Console agent

You no longer need to create the IAM role for deploying a Console agent in AWS before you start. The NetApp Console can create the role for you. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html[Learn how to deploy a Console agent in AWS from the Console^]


=== NetApp Console administration
This release includes security improvements and bug fixes as well as the following new feature.

==== Assign the Cloud Volumes ONTAP contributor role

You can now assign the Cloud Volumes ONTAP contributor role to give members broad access to manage Cloud Volumes ONTAP systems without letting them delete systems, volumes, aggregates, or replication relationships. link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-cvo-roles.html[Learn more about role-based access for Cloud Volumes ONTAP^].
