= Learn about NetApp Console
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The NetApp Console unifies storage management and protection across your hybrid multi-cloud data infrastructure with integrated data services to protect and optimize data.

Use the Console as a software-as-a-service (SaaS) application or install it in your environment (restricted or private mode). It provides storage management, data mobility, data protection, and data analysis and control. 

The Console works in tandem with Console agents that you can deploy in your environment to manage resources and processes across your on-premises and cloud environments.

== How NetApp Console works

The NetApp Console is a web-based console accessed through a SaaS application or a Console agent you install. You need to deploy additional Console agents to bridge the network gap between your storage and NetApp Console features.

=== SaaS versus installed

You can start using NetApp Console by signing up for the SaaS offering or installing it in your own cloud (restricted mode) or on your premises (private mode). Depending on how you access the Console, some features and services might not be available. When you deploy NetApp Console in the cloud (restricted mode), NetApp limits outbound connectivity to meet your organization's security and compliance requirements. Not all features and services are available when you install in your own cloud or on-premises.


link:concept-modes.html[Learn more about deployment modes].

=== Console agents

Console agents are lightweight software components that you can deploy in your environment to manage resources and processes across your on-premises and cloud environments. Console agents enable you to manage storage, use data services, and access features that require a network bridge between your storage and NetApp Console.

When you deploy NetApp Console in the cloud (restricted mode) or on-premises (private mode), you need to deploy at least one Console agent to access the Console. Depending on your use case, you might need to deploy additional Console agents to access features that require a network bridge between your storage and NetApp Console SaaS application and NetApp APIs.

link:concept-agents.html[Learn more about Console agents].

=== Identity and access management (IAM)

The Console provides identity and access management (IAM) capabilities that strengthen your security posture and governance across your data infrastructure. By organizing your storage and data services around organizational roles and responsibilities, you reduce the risk of unauthorized access while maintaining operational efficiency:

* A top-level _organization_ enables you to grant and revoke access to storage systems and projects across your entire infrastructure
* _Folders_ enable you to group storage resources and projects together based on business function or compliance requirements
* _Projects_ enable you to control which teams access specific storage systems, volumes, and data services
* _Role-based access control (RBAC)_ enables you to assign storage management permissions to team members at different levels, ensuring appropriate delegation without overprovisioning access

link:concept-identity-and-access-management.html[Learn more about IAM in NetApp Console]



== Centralized storage management

Discover, deploy, and manage all of your cloud and on-premises storage with the Console.

NetApp Console solves key storage management challenges by providing unified management of your NetApp storage infrastructure through a single interface.

_Systems_ in the Console represent your discovered or deployed storage. You can manage the storage systems directly from the Console by adding volumes directly from the Console or accessing the system's management interface. Apply data services to your storage systems to protect and optimize your data. You can also use the Console to manage your cloud storage accounts and view your storage capacity.

== Simplify Storage Operations
Direct volume management and integrated ONTAP System Manager access enable administrators to provision, configure, and manage on-premises ONTAP, AFF/FAS, and ONTAP Select systems without operational complexity.

=== Supported cloud and on-premises storage

Manage these storage types from the Console:

Cloud storage solutions::
* Amazon FSx for NetApp ONTAP
* Azure NetApp Files
* Cloud Volumes ONTAP
* Google Cloud NetApp Volumes

On-premises flash and object storage::
* E-Series systems
* ONTAP clusters
* StorageGRID systems

Cloud object storage::
* Amazon S3 storage
* Azure Blob storage
* Google Cloud Storage

== Protect and Optimize Data

Built-in data services including replication, backup, scanning, classification, and tiering enable organizations to safeguard critical data and optimize storage efficiency without deploying separate tools.

NetApp Backup and Recovery::
Back up and restore cloud and on-premises data.

NetApp Copy and Sync::
Sync data between on-premises and cloud data stores.

NetApp Disaster Recovery::
Protect on-premises VMware workloads using VMware Cloud on Amazon FSx for ONTAP as a disaster recovery site.

NetApp Ransomware Resilience::
Detect anomalies that might result in ransomware attacks. Protect and recover workloads.

NetApp Replication::
Replicate data between storage systems to support backup and disaster recovery.

== Manage Costs and Compliance
Complete tracking of hardware and software contract status across all systems supports better cost management, compliance monitoring, and informed purchasing decisions, while flexible deployment options--cloud-based agents or direct on-premises access--allow you to choose the architecture that fits your security and budget requirements.

Automation hub::
Use scripted solutions to automate the deployment and integration of NetApp products and services for greater operational efficiency and consistency.

NetApp Cloud Tiering::
Extend your on-premises ONTAP storage to the cloud for cost optimization and data lifecycle management.

NetApp Data Classification::
Get your application data and cloud environments privacy ready for compliance with data privacy regulations.

NetApp Volume Caching::
Create a writable cache volume to speed up access to data or offload traffic from heavily accessed volumes for increased performance and cost efficiency.

NetApp Workloads::
Design, set up, and operate key workloads using Amazon FSx for NetApp ONTAP to optimize performance and cost for specific applications.
