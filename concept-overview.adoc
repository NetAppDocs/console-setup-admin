= NetApp Console for unified storage management
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The NetApp Console helps you manage and protect your data across all your cloud and on-premises systems. It includes tools to keep your data safe and working well.

Use the Console as a software-as-a-service (SaaS) application or install it in your cloud or on-premises environment (restricted or private mode). Each mode supports different feature sets and security requirements.

The Console works in tandem with Console agents that you deploy in your environment to manage resources and orchestrate processes across your on-premises and cloud environments.


== Choose how to access NetApp Console

You can start using NetApp Console by signing up for the SaaS application (standard mode) or installing it in your own cloud (restricted mode) or on your premises (private mode). When you deploy NetApp Console in the cloud (restricted mode), NetApp limits outbound connectivity to meet your organization's security and compliance requirements. Not all features and services are available when you install in your own cloud or on-premises.


link:concept-modes.html[Learn more about deployment modes].

== Enable features with Console agents

Console agents are lightweight software components that provide connectivity to the NetApp Console SaaS application and cloud-based APIs, enabling advanced features and data services.

In restricted or private mode, install a Console agent in your cloud or on-premises environment to access the NetApp Console application. You need to deploy additional agents to support features that require direct connectivity to NetApp Console and its APIs.


link:concept-agents.html[Learn more about Console agents].

== Manage user access and permissions in NetApp Console

The Console provides identity and access management (IAM) to improve security and control across your data infrastructure. Organize your storage and data services around organizational roles and responsibilities to reduce the risk of unauthorized access while maintaining operational efficiency:

* A top-level _organization_ enables you to grant and revoke access to storage systems and projects across your entire infrastructure
* _Folders_ enable you to group storage resources and projects together based on business function or compliance requirements
* _Projects_ enable you to control which teams access specific storage systems, volumes, and data services
* _Role-based access control (RBAC)_ lets you give storage management permissions to team members at different levels, so you can delegate tasks without giving too much access

link:concept-identity-and-access-management.html[Learn more about IAM in NetApp Console]

== Security and compliance in NetApp Console
Enable security and compliance features like single sign-on (SSO) to control access to your storage and data services. Console administrators can enable read-only mode by default so that users must request elevated permissions to make changes to storage systems and use data services. You can also use NetApp Console to monitor storage management and user activity. NetApp Console is SOC 2 Type 2 certified, and NetApp provides SOC 2 reports to customers.

https://www.netapp.com/company/trust-center/compliance/soc-2/[View NetApp's SOC 2 reports^]



== Supported storage types, features, and data services within NetApp Console

NetApp Console supports a wide range of storage types, features, and data services across your on-premises and cloud environments. Use the Console to manage your storage systems, monitor their health and performance, and enable data services to protect and optimize your data.

=== Supported cloud and on-premises storage in NetApp Console

Manage these storage types from the Console:

Cloud storage solutions::
* Amazon FSx for NetApp ONTAP
* Azure NetApp Files
* Cloud Volumes ONTAP
* Google Cloud NetApp Volumes

On-premises flash and object storage::
* E-Series systems
* ONTAP clusters
* StorageGRID systems

Cloud object storage::
* Amazon S3 storage
* Azure Blob storage
* Google Cloud Storage


=== Storage management services in NetApp Console

NetApp Console provides unified management of your NetApp storage infrastructure through a single interface.

In the Console, _Systems_ represent your discovered or deployed storage. Perform day-to-day storage management tasks with direct volume management or by opening the system's management interface directly from the Console. 

image:screenshot-canvas.png["A screenshot of the Console that shows several systems. One is selected and shows the ability to enable NetApp data services or to select *Enter system* to manage storage."]

In addition to storage administration, use infrastructure services to monitor and manage your storage infrastructure across all your environments.


Licenses and subscriptions::
Manage and monitor your licenses and subscriptions.

Lifecycle planning::
Identify clusters low on space and add capacity or move data as needed.

NetApp digital advisor (Active IQ)::
Use predictive analytics and proactive support to optimize your data infrastructure.

Software updates::
Automate the assessment, planning, and completion of ONTAP upgrades.

Storage alerts::
View issues related to capacity, availability, performance, protection, and security in your ONTAP environment.

Sustainability dashboard::
Analyze the sustainability of your storage systems.

=== Data security and protection services in NetApp Console

Use built-in data services to protect critical data and optimize storage efficiency.

NetApp Backup and Recovery::
Back up and restore cloud and on-premises data. Requires subscription.

NetApp Copy and Sync::
Sync data between on-premises and cloud data stores.

NetApp Disaster Recovery::
Protect on-premises VMware workloads using VMware Cloud on Amazon FSx for ONTAP as a disaster recovery site. Requires subscription.

NetApp Ransomware Resilience::
Detect anomalies that might result in ransomware attacks. Protect and recover workloads. Requires subscription.

NetApp Replication::
Replicate data between storage systems to support backup and disaster recovery.

=== Cost and compliance management services in NetApp Console
Track hardware and software contract status across all systems to support better cost management, compliance monitoring, and informed purchasing decisions. 

Automation hub::
Use scripted solutions to automate the setup and connection of NetApp products and services for smoother and more consistent operations.

NetApp Cloud Tiering::
Extend your on-premises ONTAP storage to the cloud for cost optimization and data lifecycle management.

NetApp Data Classification::
Get your application data and cloud environments privacy ready for compliance with data privacy regulations. Free with subscription.

NetApp Volume Caching::
Create a writable cache volume to speed up access to data or offload traffic from heavily accessed volumes for increased performance and cost efficiency.

NetApp Workloads::
Design, set up, and operate key workloads using Amazon FSx for NetApp ONTAP to optimize performance and cost for specific applications.
