= Learn about NetApp Console
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The NetApp Console unifies storage management and protection across your hybrid multi-cloud data infrastructure with integrated data services to protect and optimize data.

Use the Console as a software-as-a-service (SaaS) application or install it in your cloud or on-premises environment (restricted or private mode). Each mode supports different feature sets and security requirements.

The Console works in tandem with Console agents that you deploy in your environment to manage resources and orchestrate processes across your on-premises and cloud environments.

== How NetApp Console works

The NetApp Console is a web-based console accessed through a SaaS application or a Console agent you install. You need to deploy additional Console agents to connect your storage to NetApp Console features.

=== SaaS versus installed

You can start using NetApp Console by signing up for the SaaS application (Standard mode) or installing it in your own cloud (restricted mode) or on your premises (private mode). When you deploy NetApp Console in the cloud (restricted mode), NetApp limits outbound connectivity to meet your organization's security and compliance requirements. Not all features and services are available when you install in your own cloud or on-premises.


link:concept-modes.html[Learn more about deployment modes].

=== Console agents

Console agents are lightweight software components that you can deploy in your environment to manage resources and processes across your on-premises and cloud environments. Console agents enable you to manage storage, use data services, and access advanced features that require a network connectivity between your storage and NetApp Console.

When you deploy NetApp Console in the cloud (restricted mode) or on-premises (private mode), you install an Console agent that is used to access the Console. Depending on the network topology of your storage infrastructure, you need to deploy additional Console agents to enable features that require a network connection between your storage and NetApp Console SaaS application and NetApp APIs.

link:concept-agents.html[Learn more about Console agents].

=== Identity and access management (IAM)

The Console provides identity and access management (IAM) to improve security and control across your data infrastructure. By organizing your storage and data services around organizational roles and responsibilities, you reduce the risk of unauthorized access while maintaining operational efficiency:

* A top-level _organization_ enables you to grant and revoke access to storage systems and projects across your entire infrastructure
* _Folders_ enable you to group storage resources and projects together based on business function or compliance requirements
* _Projects_ enable you to control which teams access specific storage systems, volumes, and data services
* _Role-based access control (RBAC)_ enables you to assign storage management permissions to team members at different levels, ensuring appropriate delegation without overprovisioning access

link:concept-identity-and-access-management.html[Learn more about IAM in NetApp Console]

NetApp does not charge for the Console. You incur costs when you deploy Console agents or use Restricted mode in the cloud. Some NetApp data services also have associated costs.

== Available data security and protection services

Use built-in data services to protect critical data and optimize storage efficiency without extra tools.

NetApp Backup and Recovery::
Back up and restore cloud and on-premises data. Requires subscription.

NetApp Copy and Sync::
Sync data between on-premises and cloud data stores.

NetApp Disaster Recovery::
Protect on-premises VMware workloads using VMware Cloud on Amazon FSx for ONTAP as a disaster recovery site. Requires subscription.

NetApp Ransomware Resilience::
Detect anomalies that might result in ransomware attacks. Protect and recover workloads. Requires subscription.

NetApp Replication::
Replicate data between storage systems to support backup and disaster recovery.

== Cost and compliance management services
Track hardware and software contract status across all systems to support better cost management, compliance monitoring, and informed purchasing decisions. 

Automation hub::
Use scripted solutions to automate the setup and connection of NetApp products and services for smoother and more consistent operations.

NetApp Cloud Tiering::

NetApp Data Classification::

NetApp Volume Caching::

NetApp Workloads::
Design, set up, and operate key workloads using Amazon FSx for NetApp ONTAP to optimize performance and cost for specific applications.
