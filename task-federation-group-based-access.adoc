= Federated identity management in NetApp Console
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
With group-based access control, you can create and manage permission groups in your identity provider (IdP) (such as Azure AD, Ping or AD FS).
Assign NetApp Console roles that map to specific IdP groups. Using federated groups, automatically assigns or revokes permissions in netApp Console for users based on their group membership in your IdP.
