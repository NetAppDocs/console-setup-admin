== Troubleshoot a failed Console agent deployment

Use the deployment report to find what blocked the Console agent deployment, and then retry it.

The Console provides a report only if the *Validate agent configuration* check box was selected. If the deployment succeeds, there is no report.

.Steps

. In the *Agent deployment failed* dialog box, select *Download report*.
+
The Console downloads a PDF file that contains the validation report.

. Review the report and fix the issues that it lists.

. In the dialog box, select *Start over*, and then complete the deployment again.
+
You must start the entire process over to try again.
