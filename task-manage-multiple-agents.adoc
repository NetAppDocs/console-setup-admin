= View systems associated with different Console agents
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
If your organization uses multiple Console agents, you can switch between them to see the systems that are associated with a specific agent.

For users with the Org admin role, this is helpful when implementing your resource management strategy. You can switch to a different agent when discovering storage systems to automatically associate those systems with the agent that is in the same environment. 

For storage administrators, switch between agents to manage the systems that are associated with each agent.

For example, in a multicloud environment, your organization might have one agent in AWS and another in Google Cloud. Switch between these agents to manage the Cloud Volumes ONTAP systems in the respective cloud environments.

NOTE: This option is not available when viewing the NetApp Console from the agent's local UI.

.Step

. Select *Storage* > *Management* > *Systems*.

. Select the Console agents icon (image:icon-agent.png[agent icon]) in the top right to view the list of available agents.
+
image:screenshot-connector-switch.png[A screenshot that shows the Agents icon in the header and the Switch action.]

.Result

The Console refreshes and shows the systems associated with the selected agent.
