= Manually deploy the NetApp Console agent in restricted mode
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
If you want to use the NetApp Console with limited outbound connectivity, you need to manually deploy the Console agent in restricted mode.

If you don't want to use a marketplace subscription or are deploying Google Cloud, you need to manually install the Console agent.

== Step 1: Prepare cloud permissions

Before you install the Console agent, prepare the cloud provider permissions it needs to manage resources.

link:task-prepare-restricted-mode.html#step-6-prepare-cloud-permissions[Learn how to prepare cloud permissions].

== Step 2: Prepare network access

Allow the outbound endpoints required for the cloud provider where you install the Console agent:

* AWS: link:task-prepare-restricted-mode.html#restricted-mode-aws-endpoints[AWS networking endpoints]
* Azure: link:task-prepare-restricted-mode.html#restricted-mode-azure-endpoints[Azure networking endpoints]
* Google Cloud: link:task-prepare-restricted-mode.html#restricted-mode-google-cloud-endpoints[Google Cloud networking endpoints]

For shared NetApp Console, NSS, and upgrade endpoints, see link:task-prepare-restricted-mode.html#restricted-mode-console-endpoints[Shared NetApp Console endpoints].

For browser access and other networking requirements, see link:task-prepare-restricted-mode.html#step-5-prepare-network-access[Prepare network access for restricted mode].

The Console agent is now installed. At the end of the installation, the Console agent service (occm) restarts twice if you specified a proxy server.

.What's next?

Set up the NetApp Console.

== Step 4: Set up NetApp Console

When you access the console for the first time, you are prompted to choose an organization for the Console agent and need to enable restricted mode.

.Before you begin

The person who sets up the Console agent must log in to the Console using a login that doesn't already belong to a Console organization.
 
If your login is associated with another organization, you need to sign up with a new login. Otherwise, you do not see the option to enable restricted mode on the setup screen.

.Steps

. Open a web browser from a host that has a connection to the Console agent instance and enter the following URL of the Console agent you installed.

. Sign up or log in to the NetApp Console.

. After you're logged in, set up the Console:

.. Enter a name for the Console agent.

.. Enter a name for a new Console organization.

.. Select *Are you running in a secured environment?*

.. Select *Enable restricted mode on this account*.
+
Note that you can't change this setting after the account is created. You can't enable restricted mode later and you can't disable it later.
+
If you deployed the Console agent in a Government region, the checkbox is already enabled and can't be changed. This is because restricted mode is the only mode supported in Government regions.

.. Select *Let's start*.

.Result

The Console agent is now installed and set up with your Console organization. All users need to access the Console using the IP address of the Console agent instance.

.What's next?

Provide the Console with the permissions that you previously set up.
